## 🎛️ Live production & show control ## <br>

💾 Windows applications.<br>
**[VariABLE OSC](https://github.com/beardedhummus/VariableOSC)**: pulls live values out of Windows apps that have no API by scanning their memory and broadcasts them over OSC. Has a "Make Permanent" wizard that finds pointer paths so variables survive restarts. Made with Companion in mind.
<br>`C#` `.NET` `WinForms` · *built*

**[HogOSC](https://github.com/beardedhummus/HogOSC)**: sends the active cue name and number from an ETC Hog 4 lighting console out over OSC, including previous/next cue. Made with Companion in mind. Buttons always show current information. It listens passively on the network and never touches the console. 
<br>`C#` `.NET` `WinForms` `Npcap` · *built: running in live productions* 

🍎 Mac applications.
**[Broadcast Browser](https://github.com/beardedhummus/Broadcast-Browser)**: a macOS app that turns browser tabs into video sources for broadcast, with output to Blackmagic DeckLink, NDI, Syphon, an HDMI display, or a recording. Supports cropping, an edit mode for the hosted websites, and remote OSC control. 
<br>`Swift` `SwiftUI` `ScreenCaptureKit` `WebKit` · *built: needs more testing* 

💻 Chrome extensions.<br>
**[Companion Theme Studio](https://github.com/beardedhummus/companion-theme-studio)**: a Chrome extension that restyles the Companion web interface with 10 themes and full color customization, without touching the button grid or Stream Deck emulator.
<br>`JavaScript` `Chrome Extension (MV3)` · *beta: runs in my browser*

⌨️ Web applications.<br>
**[TeleTimer](teletimer.jameslavranos.com)**: a simple timer/countdown app built for beamsplitter teleprompter glass that gives the user vertical and horizontal axis flip control so it reads correctly through the glass. This is made specifically for people who prefer a timer/countdown rather than a script.
<br>`HTML` `CSS` `JavaScript` · *[live at teletimer.jameslavranos.com]*

🕹️ Companion modules.<br>
**[BetterOSC](https://github.com/beardedhummus/Better-OSC)**: a replacement for the native Generic OSC module that ships with Companion. Scans a port for incoming OSC. Automatically creates variables for addresses, arguments, and values.
<br>`JavaScript` `Node.js` · *built: running in live productions* 

## 🖥️ Mac apps
Currently in development. 

**[Roebuck]()**: a native ePub studio for macOS. Rich-text editor for ePub creation for authors. Imports PDF (with OCR), Word, RTF, and Markdown with a number of smart features. Exports reflowable or fixed-layout ePub and print-ready PDF. Includes an e-ink preview, pop-up footnotes and chapter snapshots.

<br>`Swift` `SwiftUI` `WidgetKit` · *beta*

## 🌐 Self-hosted web apps
These all run on my own home server behind Cloudflare.

**[Dispatch](https://blog.jameslavranos.com)**: a self-hosted blogging platform you can run in Docker. Rich-text editor, scheduled posts, revisions, image crops, and an RSS feed. It powers [blog.jameslavranos.com](https://blog.jameslavranos.com).
<br>`Node.js` `Express` `React` `TipTap` `SQLite` `Docker` · *live*

**[Cut the Check]()**: a real-time party game for friend groups with fake money: payroll, loans, credit scores, a stock market, a casino, lawsuits with a jury, careers, businesses and hilarious consequences. Played as an installable phone web app.
<br>`Swift (server)` `TypeScript` `React` `Docker` · *built, testing locally, currently invite-only*
